Antarmuka dan koleksi project sudah terpasang. Selesaikan koneksi Decap Turbo untuk mengaktifkan login dan penyimpanan ke GitHub.

  4. Ganti nilai REPLACE_WITH_DECAP_TURBO_SITE_ID pada public/admin/config.yml.
